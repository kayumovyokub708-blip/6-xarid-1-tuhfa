## 2. Матни пурраи карточка

**Сарлавҳа:**  
★  6 ХАРИД — 1 ТӮҲФА!  ★

**Шуор:**  
6 бор аз мо харид кун — тӯҳфаи худро бигир!

**Хоначаҳо:**  
6 хоначаи калон бо рақамҳои 1 то 6.  
Ҳар хонача ҷой барои муҳр / стикер / имзои корманд дорад.

**Блоки тӯҳфа:**  
★ ТӮҲФАИ ШУМО ★  
САБАДИ МАҲСУЛОТ  
БА АРЗИШИ 80 СОМОНӢ

**Қоидаҳои кӯтоҳ (дар поёни карточка):**  
1. Бо ҳар харид 1 хонача пур карда мешавад.  
2. Пас аз 6 хонача → тӯҳфа гиред.  
3. Карточкаро ба корманд нишон диҳед.  
4. Як карточка = як тӯҳфа.

## 3. 6 хонача бо рақамгузорӣ

```
┌─────┐  ┌─────┐  ┌─────┐
│  1  │  │  2  │  │  3  │
│     │  │     │  │     │
└─────┘  └─────┘  └─────┘

┌─────┐  ┌─────┐  ┌─────┐
│  4  │  │  5  │  │  6  │
│     │  │     │  │     │
└─────┘  └─────┘  └─────┘
```

Пас аз ҳар харид танҳо **1** хонача пур карда мешавад.  
Вақте ки хоначаи 6-ум пур шуд → карточка пурра ҳисобида мешавад.

---

## 4. Матни қоидаҳо (пурра)

1. Бо ҳар харид 1 хонача пур карда мешавад.  
2. Пас аз пур шудани 6 хонача карточка пурра мешавад.  
3. Пас аз пур шудани карточка мизоҷ тӯҳфаи худро мегирад.  
4. Барои гирифтани тӯҳфа карточка бояд ба корманди мағоза пешниҳод карда шавад.  
5. Як карточка танҳо барои як тӯҳфа истифода мешавад.

## 9. Пешниҳоди тарзи гузоштани бозӣ дар мағоза

1. **Дар назди касса** — плакат ё карточкаҳои холӣ гузоред.  
2. **Дар рафҳои асосии маҳсулот** — стикерҳои хурд бо матн: «6 харид = тӯҳфа!»  
3. **Ҳангоми харид** — корманд ба мизоҷ карточка медиҳад ва шарҳ медиҳад.  
4. **Дар тиреза / девор** — плакати калон бо намунаи сабад.  
5. **Дар WhatsApp / Instagram** — акси карточка ва сабадро нашр кунед.
