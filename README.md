# ★ 6 ХАРИД — 1 ТӮҲФА! ★  
### Мағозаи хӯроквории **«ШАҲОБ»**

Карточкаи **дутарафа** (A6):

- **Тарафи пеш** — бозӣ ва 6 хонача
- **Тарафи пушт** — суратҳои маҳсулот (равған, биринҷ, шакар, макарон, печенье, шоколад, нӯшокӣ, аробача) + бренди Шаҳоб

## Шарти асосӣ
Ҳар харид **аз 260 сомонӣ боло** = 1 хонача  
Пас аз **6** хонача → **сабади 100 сомонӣ**
